FEATURE 04

Price Reduction Tool

Find and remove quotation prices while keeping technical and supplier information intact.

1. Select a quotation PDF

Choose a PDF quotation to inspect it in your browser.

No file selected

Your file is processed locally in this browser.

2. Review detected prices

Select matches to remove from the exported copy. Detection is pattern-based; verify each page.

Current capabilities

  • Detects selectable PDF text containing common currency symbols/codes and price-related labels.
  • Creates a flattened PDF copy; the original file is not changed.
  • Files stay in your browser during processing.
Important: This initial version does not OCR scanned PDFs or reliably detect prices written in words. Review every match and every page before using the output. The exported PDF is image-based, so text search/copy may be lost.
