FEATURE 04

Price Reduction Tool

Edit selectable quotation text directly, or cover and replace text in scanned and image-based PDFs.

1. Open quotation

No file selected

Your file stays in this browser. The original is never changed.

2. Edit quotation text

Page —

Choose Edit existing text to click selectable PDF text, or Cover & replace to draw a box over text. Scanned PDFs work with cover-and-replace.

How it works

  • Use Edit existing text for selectable PDF text, or Cover & replace for scanned PDFs. Apply each replacement before exporting.
  • Enable drag-to-remove to erase as many areas as you want.
  • Works with selectable-text and scanned/image PDFs because you mark visible areas.
  • Export creates a flattened PDF copy. The original is unchanged.
Please check the page before exporting. Rectangle removal covers everything inside the box, so keep the box tight around the text you want removed. The exported PDF is image-based; text search/copy may be lost.
